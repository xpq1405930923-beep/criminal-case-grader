# Criminal Case Grader

一个用于中国刑法案例分析题批改的 Codex Skill。

## 功能

- 刑法案例分析题智能阅卷
- OCR 识别学生答案
- 20 分制采点评分
- 分析犯罪构成、共同犯罪、罪数等问题
- 自动生成可编辑 Word 批改报告
- 支持红、绿、蓝等颜色标注
