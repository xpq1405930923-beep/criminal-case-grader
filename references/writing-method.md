## 一、先读题：区分“行为数量”和“行为性质”

1. 以设问为边界，列出各行为人、时间顺序、积极行为与不作为，以及与定罪量刑有关的事实。内部可用甲 a1、a2，乙 b1、b2 标记；最终卷面不展示这种工作编号。
2. 检查举动是否可在相应犯罪构成内合并评价，结合主观犯意与客观行为判断；不得简单以“出现几个动词”计算罪数，也不得把“同一目的”一律当作一个犯罪。
3. 分别检查两种遗漏：**数量遗漏**是完全漏掉一段独立犯罪行为；**性质遗漏**是已分析某行为，却漏掉其另一个应评价的法律性质。每一遗漏只映射其对应采分点，防止重复扣失。
4. 根据具体适用规则处理一罪、竞合、吸收、并罚等问题。源书“一行为定一罪”等图示是简化提示，不能代替具体罪数判断；一个行为涉及多个罪名时，仍须说明应评价的性质及处理原则。
5. 对题目真正设置的罪与非罪、此罪与彼罪、犯罪停止形态、共犯范围、罪数及量刑争点逐一覆盖；不要在狭窄设问下强行展开无关内容。

## 二、再写答案：明示结论、按人组织、交代处罚

1. **明示结论。** 每问先写准确的罪名或法律性质，再用关键事实说明理由。共同犯罪、角色、未遂或中止等必要结论须明确写出。阅卷只能根据考生实际表达给分，不替考生补足未写内容；可接受含义清晰、法律意义等价的措辞，无须逐字匹配参考答案。
2. **按人定罪。** 原则上依甲、乙、丙分点。构成同一共同犯罪、罪名及共性理由相同的，可合并写；罪名或责任范围不同的，分别写清。即使合并，共犯角色、实行过限、个人量刑情节也须分别评价。
3. **罪数算总账。** 某行为人涉及多个罪名时，在其相关分析结束处明确最终处理：哪些罪名、是否并罚、是否从一重罪处罚或适用特定一罪规则。仅罗列罪名不等于已经说明罪数结论。
4. **量刑写全两层。** 先说明具备何种情节及对应事实，再写其处理原则，准确区分“应当／可以”“从重／从轻／减轻／免除”。不把“有某情节”与“说对该情节的处罚效果”视为同一采分内容；具体如何拆分，依本题评分细则。

## 三、理由写法：插入式造句法

源书正式名称是“插入式造句法”，不是“法理分析法”。其要点是把法律规则关键词与本案事实关键词合在一句或少数几句中。

1. 提取规则关键词：相关故意、过失或特定目的；实行行为及必要关系；法律要求的结果。没有特定目的或结果要求时，不生造要素。
2. 提取事实关键词：谁、对谁、具体做了什么、如何实施、发生何种必要结果。将事实嵌入规则关键词，避免只背罪名定义。
3. 用“主观＋客观＋必要结果／关系＋性质”的检查框架组织简短理由。这是本 skill 对源书方法的实施概括，不要求每句机械写满四项，也不要求把“主观上”“客观上”当成得分暗号。
4. 可用的卷面结构：`甲构成［罪名／形态］。甲基于［有依据的故意或目的］，实施［本案关键行为］，［必要结果或构成关系］，故［结论］。`
5. 对题目设置的易混淆定性，先说明为何成立 A，再用一项有区分力的事实解释为何不成立 B。只对相关争点做正反辨析，不列一串无关罪名凑字数。
6. 保留必要的规范术语，允许准确的同义表达。一般不必完整抄写定义、法条或四要件；也不把内部判断口诀直接当作理由。

## 四、把方法转为采分检查，而非额外扣分表

| 检查内容 | 阅卷处理 |
| --- | --- |
| 定性、罪名、犯罪形态、共犯或罪数结论 | 对照本题采分点，分别核对是否明确且正确；不以隐含猜测补给分。 |
| 规则与事实结合 | 检查是否把具体事实用于构成要件或争点论证；纯定义只评价其实际覆盖的内容。 |
| 正反辨析 | 仅当设问、案情或评分细则使该区分成为必要争点时设采分点，不普遍增设“反面论证分”。 |
| 量刑情节及处理原则 | 核对成立依据，以及“应当／可以”和处罚幅度用语；允许按明确细则给部分分。 |
| 错字、结构、篇幅 | 提出针对性建议。罪名错写若改变法律含义，按对应实质采分点处理；一般排版或表达问题不另扣分。 |

- 每道完整案例题满分 **20 分**，其所有小问共享这 20 分。分配依据由主流程处理；源书“结论 2 分＋理由 4 分”等示例不能套到所有试题。
- 源书第 84 行的“错别字一般扣 2 分”属于书中经验性说法，**不得设置为本 skill 自动扣 2 分规则**。没有明确适用的正式评分标准时，按错误是否影响本题采分点评价，不叠加惩罚。
- 源书第 104 行虽然批评答案解析化，却明确说明其示例从简到详的四种答案均可满分。因此，冗长但实质正确的答案照常按采分点给分；精简建议不等于扣分理由。
- 源书关于“三段论”“四要件”写法的批评是备考效率建议。若考生采用这些结构且结论、事实论证与必要要点正确，不因采用某种结构扣分。
- “明示规则”要求意思表达清楚，不要求口令匹配。结构混乱但可准确对应的正确内容，仍计入相应采分点；重复作答不得重复得分。

## 五、最终卷面答案自查

- 严格按原题小问顺序回答，使用短段和必要编号。
- 每问有结论及关键事实理由；同罪共性可合并，差异责任明确区分。
- 必要时写清罪数处理与量刑原则；不漏独立行为或应评价的性质。
- 理由采用法律关键词与事实关键词结合的简明表达，删去授课旁白、推理草稿、评分符号和对考生的评价。
- 标准答案正文保持能直接誊写在法硕入学考试答卷上的形式；分值、批注、争议说明与来源信息留在阅卷说明部分。
